
# Описание проекта
Данный репозиторий содержит практическую часть выпускной квалификационной работы "Методы детекции людей на изображениях, полученных с помощью беспилотных летательных аппаратов". 
Проект представляет собой реализацию системы детекции людей на изображениях с БПЛА с помощью YOLOv11m с использованием предварительной обработки изображений с помощью алгоритма CLAHE с оптимизацией на GPU.

# Пример использования системы
```bash
python src/main.py -i (input_path) -p (processed_save_path) -d (detection_result_path)
```

# Структура репозитория
* `src/detection/` - содержит функционал детекции объектов, а так же обученные модели детекции для различных параметров предварительной обработки.
* `src/image_processing.` - содержит функционал обработки изображений и взаимодействия с GPU
* `src/test.` - содержит функционал тестирования на датасете. `src/test/testing_results.` содержит использованые в тексте ВКР результаты тестирования в виде таблиц и сформированных на их основе графиков.
